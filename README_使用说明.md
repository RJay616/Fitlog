# TaiChiFlow / FitLog v1.2（Android PWA）

一个纯前端的气功、太极与经络跟练工具。数据全部保存在手机浏览器本地，不需要服务器，也不上传视频或训练记录。

## 文件清单

需要替换到 GitHub Pages 仓库根目录的文件：

- `index.html`：页面结构（v1.2）
- `styles.css`：样式（新增下拉刷新拦截相关样式）
- `app.js`：核心逻辑（本次主要改动）
- `sw.js`：离线缓存（版本升到 1.2，会自动清理旧缓存）
- `manifest.webmanifest`：PWA 配置（版本标为 1.2）
- `icon.svg`、`icon-192.png`、`icon-512.png`：图标（无需修改，保留即可）

> 同目录下的 `index-0.html`、`styles-1.css`、`sw-1.js` 是旧备份，不需要上传，也不需要删除。

## 升级替换方法

### GitHub Pages 更新

1. 把上面 5 个修改后的文件上传到仓库根目录，覆盖旧文件。
2. 提交（commit）后等待 GitHub Pages 重新发布，通常 1～2 分钟。
3. 手机首次打开新版本时，Service Worker 会自动更新缓存；如果界面仍是旧的，下拉刷新一次或完全关闭网页再打开。
4. 如果已经把网页安装到桌面，且界面没有变化，可删除桌面图标后重新「安装应用」。这不会删除网页数据，但为了避免意外，重要编排建议先用 DeepSeek 复制功能留一份文本备份。

### 电脑本地测试

1. 用 VS Code 打开项目文件夹。
2. 安装扩展 `Live Server`。
3. 右键 `index.html` → `Open with Live Server`。
4. 不要直接双击 `index.html`，`file://` 模式下 Service Worker 和部分本地存储功能不可用。

## 功能使用说明

### 1. 训练主页

- 点击「开始全套训练」按顺序执行当前编排。
- 常规动作按设定的时长、次数和组间休息运行；倒计时最后 3 秒有滴滴声。
- 纯视频动作不计时，视频播放完毕自动进入下一项。
- 「上一个」「下一个 / 跳过休息」可手动控制进度。

### 2. 动作元件

- 填写动作名称，可选选择本地视频。
- 勾选「纯视频跟练」后，下面的时长、计数、组间休息会变灰并失效；此时必须选择视频文件。
- 添加的动作保存在本机浏览器数据库中，视频也会保存在本机 IndexedDB，刷新页面后仍可跟练。
- 删除动作时会同时删除对应的本地视频。

### 3. 设置与缓存

两个入口都可以进入：

- 首页 hero 卡片里的「缓存清理」按钮；
- 底部导航的「设置与缓存」。

缓存分为：

- **有用缓存**：动作编排、本地视频、离线页面外壳。清理后动作恢复为默认 3 项，需重新添加。
- **无用缓存**：临时日志、过期缓存。清理不影响当前编排。

勾选后点「清理所选缓存」，并确认弹窗即可。

### 4. 语音与提示音自检

在「设置与缓存」页：

- 「测试滴滴倒计时音」：检查提示音和媒体音量；
- 「测试语音播报与计数」：检查系统中文语音是否可用。

如果语音仍然断续，建议：

1. 在手机「设置 → 系统 → 文字转语音输出」中安装/选择中文离线语音包；
2. 关闭省电模式对浏览器的限制；
3. 保持页面在前台训练，锁屏后 Android 可能限制网页计时和语音。

### 5. 一键复制数据给 DeepSeek

点击首页或设置页的复制按钮，会把当前编排整理成一段中文说明复制到剪贴板，并自动打开 DeepSeek，直接粘贴即可让 AI 分析训练强度与经络覆盖情况。

## 数据与安全说明

- 训练编排和视频都只存在当前浏览器/当前设备的本地存储中，不会上传。
- 清理 Chrome 网站数据、卸载重装浏览器、使用系统清理工具删除应用数据，都会删除这些记录。
- 更换手机不会自动同步；请先用「复制数据并跳转 DeepSeek」保留一份文本备份。
- 本工具用于个人养生跟练参考，不提供医疗诊断。疼痛或不适时请停止练习并咨询专业人士。
