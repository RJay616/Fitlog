# FitLog V1.0（Android PWA）

这是一个面向个人使用的运动训练记录工具。第一版使用 HTML/CSS/JavaScript + IndexedDB，不需要服务器数据库或付费 API。

## 文件说明

- `index.html`：应用页面结构
- `styles.css`：手机界面样式
- `app.js`：动作库、课程、训练流程、数据记录与导出
- `manifest.webmanifest`：PWA 安装配置
- `sw.js`：离线缓存
- `icon.svg`、`icon-192.png`、`icon-512.png`：应用图标

## 最简单的电脑本地测试

1. 将项目文件解压到电脑文件夹。
2. 用 VS Code 打开文件夹（也可以使用其他编辑器）。
3. 安装 VS Code 扩展 `Live Server`。
4. 右键 `index.html`，选择 `Open with Live Server`。
5. 浏览器打开后测试动作库、创建课程、完成训练、查看历史、导出 JSON。

注意：不要直接双击 `index.html` 用 `file://` 方式测试。PWA 的 Service Worker 需要 HTTPS 或 localhost 环境。

## 免费发布到 GitHub Pages

1. 注册或登录 GitHub。
2. 创建一个新的 Public repository，例如 `fitlog`。
3. 将本项目中的所有文件上传到仓库根目录，确保 `index.html` 位于根目录。
4. 进入仓库 `Settings` → `Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. Branch 选择 `main`，目录选择 `/ (root)`，保存。
7. 等待 GitHub Pages 发布，通常会生成 `https://你的用户名.github.io/fitlog/` 这样的地址。
8. 用红米 K70 至尊版的 Chrome 打开该 HTTPS 地址。

如果你使用其他仓库名称，最终网址中的路径也要相应变化。不要把仓库设为 Private，免费 Pages 的可用范围可能受 GitHub 方案限制。

## 红米 K70 至尊版安装

建议先用 Chrome 测试：

1. 手机连接网络，打开 GitHub Pages 地址。
2. 等页面完全加载后，点击 Chrome 右上角 `⋮`。
3. 选择 `安装应用` 或 `添加到主屏幕`（不同 Chrome 版本文案可能不同）。
4. 按提示确认，桌面会出现 FitLog 图标。
5. 首次安装后保持页面打开一会儿，让离线缓存完成。之后可以尝试断网重新打开。

小米系统也可能通过系统浏览器提供“添加到桌面”入口；如果 Chrome 没有安装入口，先确认网址是 HTTPS、manifest 和 Service Worker 均成功加载，再尝试 Chrome 菜单。

## 重要的数据说明

- 训练数据存在当前浏览器的 IndexedDB 中，不会自动同步到其他设备。
- 不要清理 Chrome 的网站数据，否则可能删除训练记录。
- 建议每周进入“我的 → 导出完整备份（JSON）”，将备份文件另存到电脑或网盘。
- 更换手机时，在新手机打开 FitLog 后，使用“从备份恢复（JSON）”。
- 恢复备份会覆盖新手机当前 FitLog 数据，请先确认文件正确。
- PWA 删除/重装、浏览器清理数据、系统清理工具均可能影响本地数据。备份是必要的。

## V1.0当前范围与限制

- 动作库支持次数型、负重型、时间型、左右侧型基础分类。
- 训练过程可逐组记录次数/秒数和重量，并有语音提示、组间休息计时。
- 当前语音依赖浏览器和 Android 系统提供的语音合成服务；是否有中文声音、锁屏时能否持续播报，取决于手机系统设置和浏览器行为。
- 训练计时在前台页面使用时最可靠。Android 可能限制后台网页计时；第一版不保证锁屏后倒计时与语音始终准确。
- 当前版本暂不包含视频上传、摄像头动作识别、云同步和 AI 分析。
- 这是个人训练记录工具，不提供医疗诊断或动作安全保证。疼痛或不适时应停止相关动作并评估情况。

## 建议的首次测试流程

1. 在动作库中打开“徒手深蹲”，查看动作说明。
2. 新建课程“测试课程”，选深蹲和臀桥，各设置2组、目标10次、休息10秒。
3. 开始训练，输入实际完成次数，完成第一组。
4. 检查休息倒计时，跳过休息或等待结束。
5. 完成课程，进入“记录”查看详情。
6. 进入“我的”分别导出 JSON 和 CSV。
7. 用 JSON 备份恢复测试（建议先留好原始备份）。
