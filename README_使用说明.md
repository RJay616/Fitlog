# FitLog v1.3（Android PWA · 普通运动训练版）

FitLog 是个人运动训练记录与指导工具：动作库、训练课程、训练执行、历史趋势、数据备份全部保存在手机浏览器本地，不需要服务器。

> 本版本以 FitLog 普通运动版为基准（`index-1.html / styles-1.css / app-1.js / sw-1.js`），不是太极/气功版本。

## 文件清单

上传到 GitHub Pages 仓库根目录的文件：

- `index.html`：页面结构（含语音音色设置）
- `styles.css`：样式
- `app.js`：全部功能逻辑
- `sw.js`：离线缓存（版本号 `1.3`，旧缓存自动清理）

- `README_使用说明.md`：本说明

目录下的 `index-1.html`、`styles-1.css`、`app-1.js`、`sw-1.js` 及 `*-0.*` 是备份文件，不需要上传，也不需要删除。

## 升级方法

1. 用修改后的文件覆盖 GitHub Pages 仓库里的同名文件并提交。
2. 等待 Pages 发布完成后，手机下拉刷新一次或重新打开网页。
3. 如果已安装到桌面的 PWA 仍显示旧界面，删除桌面图标后重新安装即可。训练数据存在 IndexedDB，不会因重装 PWA 而丢失。

## 功能说明

### 语音音色设置（新）

位置：「我的」→「数据与备份」→「语音音色设置」。

- **播报模式**
  - 完整播报：报数 + 提示语；
  - 仅报数：跳过长句提示，只保留报数（适合觉得话多时）；
  - 仅滴滴提示音：完全不说话，只靠提示音节奏。
- **语音音色**：默认「自动优选男声」；也可在下拉里手动挑一个本机声音。声音列表来自手机系统，不同手机可用的声音不同。
- **音调 / 语速**：默认音调 `0.9`（偏低更像男声）、语速 `1.0`，可按需滑动调整。
- 设置保存在本机，改完点「试听当前音色」确认效果。

> 如果自动挑的声音不满意，手动在「语音音色」里选一个带「男声 / Male / Yunxi / Kangkang」等字样的即可。

### 节拍报数（新）

- 有节拍的动作（如深蹲、俯卧撑）：每秒滴一声掌握节奏，**每完成一次动作报一个数**（1、2、3…），不再播报「吸气下蹲、呼气站起」等描述。
- 无节拍的动作（如平板支撑、臀桥）：每秒滴一声并累计秒数，直接跟着节奏做即可。
- 组间休息：进入响一次、最后 3 秒各响一次、结束响三连音。

### 一键复制并打开 DeepSeek

在「我的」→「数据与备份」点击「复制数据并跳转 DeepSeek」：

1. 先把动作库、课程编排和最近 5 条训练记录整理成中文提示词复制到剪贴板；
2. 优先尝试唤起手机上的 **DeepSeek App**（安卓用官方包名 `com.deepseek.chat`）；
3. 若 1.6 秒内没唤起（没装 App 或系统不支持），自动回退打开网页版 `chat.deepseek.com`；
4. 打开后长按输入框粘贴即可。

> 说明：网页能否唤起 App 取决于手机系统和是否安装 DeepSeek；唤起失败会自动用网页版兜底，不影响复制的数据。

### 下拉刷新

在任意页面顶部下拉，只刷新当前页面的数据，不会跳回首页；当前所在菜单会被记住。**在弹窗内部上下滑动是正常滚动，不会触发刷新。**

### 纯视频跟练

1. 在「动作」页添加或编辑动作；
2. 勾选「纯视频跟练」，下方组数、次数、重量、休息、节拍等参数会变灰失效；
3. 上传本地视频或填写视频链接并保存；
4. 把该动作加入课程并开始训练，视频会放大播放，播完自动进入下一项。

> 纯视频模式暂时不统计组数、次数和重量，后续需要时再开放参数统计。

### 缓存清理

两个入口：

- 首页快捷入口里的「缓存清理」；
- 底部导航「我的」→「数据与备份」→「缓存清理（分级清理）」。

分类：

- **有用缓存**：当前版本离线页面缓存，清理后联网打开会自动重建；
- **无用缓存**：旧版本残留缓存，可安全清理。

训练数据、动作视频和实际记录**不在**缓存清理范围内，请放心使用。

## 数据与备份

- 动作、课程、训练记录和本地视频都存在 IndexedDB，不会自动上传。
- 请定期使用「导出完整备份（JSON）」保存数据；JSON 备份会跳过大体积视频文件。
- 若想删除已上传的视频：动作页 → 编辑该动作 → 教学视频栏点「移除视频」→ **保存动作**，视频文件才会真正删除并释放空间。
- 清理 Chrome 网站数据、卸载浏览器、更换手机都会导致本地记录丢失，请务必备份。
