# FitLog v1.9（Android PWA · 普通运动训练版）

FitLog 是个人运动训练记录与指导工具：动作库、训练课程、训练执行、历史趋势、数据备份全部保存在手机浏览器本地，不需要服务器。

> 本版本以 FitLog 普通运动版为基准（`index-1.html / styles-1.css / app-1.js / sw-1.js`），不是太极/气功版本。

## 升级方法

1. 用修改后的文件覆盖 GitHub Pages 仓库里的同名文件并提交。
2. 等待 Pages 发布完成后，手机下拉刷新一次或重新打开网页；若仍显示旧界面，把 App 从后台彻底清掉再打开。
3. 如果已安装到桌面的 PWA 仍是旧界面，删除桌面图标后重新安装即可。训练数据存在 IndexedDB，不会因重装 PWA 而丢失。

## 功能说明

### 全自动训练流转（新）

开始课程后，只要跟着节拍做完目标次数，程序会**自动**完成后续流程：

1. 自动记录本组次数；
2. 自动进入组间休息倒计时（进入响一次、最后 3 秒各响一次、结束响三连音）；
3. 休息结束自动开始下一组；
4. 同一动作所有组做完后，自动休息并进入下一个动作。

无节拍动作（如平板支撑）仍需在结束时点一次"完成本组"。全部完成后点"保存并结束"。中途如需临时停止，用页面底部倒计时两侧的黄色暂停键 / 红色停止键（见下）。

### 暂停、继续与退出续练

训练界面**右上角只有「🔊 重播提示」和「× 退出」**；暂停/结束在**页面最下方的倒计时两侧**：

- **⏸ / ▶ 暂停 / 继续（黄）**：位于倒计时左边。按下暂停时计时、视频、语音全部停下，屏幕显示"训练已暂停"遮罩，按钮变成 ▶；**再按一次即从暂停处继续**（节拍阶段会重新开始该阶段的秒数）。同一个按钮完成暂停与继续。
- **⏹ 停止（红）**：位于倒计时右边。确认后保存已完成的组并结束本次训练；若一组都没完成则不保存记录。
- **🔊 重播提示**：右上角，随时重听当前动作要领。
- **× 退出**：保存当前进度快照后退出，不计入本次数据。

**退出后再回来**：只要这次训练没完成、也没点"结束"，下次打开 App 会弹出"继续上次训练？"的提示，点「继续训练」即可从暂停点恢复，点「放弃」则清除快照。切到后台或误关页面也会自动保存快照。快照仅保存在当前浏览器会话中。

### 节拍彩色圆形提示（新）

- 编辑动作 →「呼吸与节拍节奏引导」→ 每个阶段中间新增了**颜色块**，点它可自定义该阶段颜色；
- 内置模板默认：吸气=绿、呼气=红、保持/停顿=黄；
- **运动过程中（v1.9 调整）**：屏幕中间是一个**放大到原来两倍的彩色圆**（约 280px），背景为当前阶段颜色，**圆内只有节拍描述黑色汉字（v1.9 再放大一倍）**，不再显示倒计时数字；
- 页面**最下方**是**去掉背景框和标题的 54px 黑色大倒计时数字**，数字上方是"已完成 X / Y 次"，数字**左边黄色暂停/继续键、右边红色停止键**；
- 右上角是「🔊 重播提示」和退出 ×。
- 准备、组间休息、纯视频阶段样式不变。

### 左右两侧分步（新）

编辑动作时勾选「左右两侧分步」，适合弹力带后踢腿这类单侧动作：

1. 一组内**先做左侧**目标次数；
2. 左侧完成 → 自动休息 **20 秒**，利用这段时间换到右侧；
3. 右侧完成 → 本组才结束 → 自动组间休息 → 下一组；
4. 历史记录里左右次数分开显示（左 X 次 / 右 X 次）。

> 旧的动作若"记录类型=左右侧型"也会自动按分步流程处理。

### 一键复制并跳转 DeepSeek

位置：「我的」→「数据与备份」→「复制数据并跳转 DeepSeek」。复制动作库、课程和最近 5 条训练记录后调起系统分享面板，选 DeepSeek 即把数据带进输入框；不支持时回退网页版。不再打开 Google Play 商店页。

### 纯视频跟练

编辑动作勾选「纯视频跟练」后，统计类参数变灰失效，但**起势准备缓冲仍可设置（默认 10 秒）**；上传视频或填链接并保存；训练时会先走准备倒计时，再放大播放视频，播完自动进入下一项。该模式暂不统计组数/次数/重量。

### 语音播报与插播（v1.9 新机制）

- **保护式队列**：动作要领、开始提示这类长句一旦开始播，会**完整念完**；期间的报数只发滴声保持节奏，数字语音在队列里排队，等长句播完自动补播，不再互相打断。
- **每 5 次插播**：填写动作的「专属语音播报」后，训练中每完成 5 次，会在报下一个数的滴声后再念一遍这段内容（到本组目标次数时不再插播）。长句超时限制已放宽，系统语速慢也不会被中途掐断。

### 下拉刷新

任意页面顶部下拉只刷新当前页，不跳首页；当前菜单会被记住。弹窗内上下滑动是正常滚动，不触发刷新。

### 删除训练记录

首页「最近训练」和「记录」页的每条记录卡片上都有**「删除记录」**按钮，点击并确认后即从本地数据库永久移除该条记录（不可恢复，建议先导出 JSON 备份）。列表和统计数字会立即更新。

## 数据与备份

- 动作、课程、训练记录和本地视频都存在 IndexedDB，不会自动上传。
- 请定期用「导出完整备份（JSON）」保存数据；JSON 备份会跳过大体积视频文件。
- 删除已上传视频：动作页 → 编辑该动作 → 教学视频栏点「移除视频」→ **保存动作**，视频文件才会真正删除并释放空间。
- 清理 Chrome 网站数据、卸载浏览器、更换手机都会导致本地记录丢失，请务必备份。
