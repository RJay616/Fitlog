# FitLog v1.5（Android PWA · 普通运动训练版）

FitLog 是个人运动训练记录与指导工具：动作库、训练课程、训练执行、历史趋势、数据备份全部保存在手机浏览器本地，不需要服务器。

> 本版本以 FitLog 普通运动版为基准（`index-1.html / styles-1.css / app-1.js / sw-1.js`），不是太极/气功版本。

## 升级方法

1. 用修改后的文件覆盖 GitHub Pages 仓库里的同名文件并提交。
2. 等待 Pages 发布完成后，手机下拉刷新一次或重新打开网页；若仍显示旧界面，把 App 从后台彻底清掉再打开。
3. 如果已安装到桌面的 PWA 仍是旧界面，删除桌面图标后重新安装即可。训练数据存在 IndexedDB，不会因重装 PWA 而丢失。

## 功能说明

### 全自动训练流转（新）

开始课程后，只要跟着节拍做完目标次数，程序会**自动**完成后续流程：

1. 自动记录本组次数；
2. 自动进入组间休息倒计时（进入响一次、最后 3 秒各响一次、结束响三连音）；
3. 休息结束自动开始下一组；
4. 同一动作所有组做完后，自动休息并进入下一个动作。

无节拍动作（如平板支撑）仍需在结束时点一次"完成本组"。训练全程可点右上角 × 退出（数据不保存），全部完成后点"保存并结束"。

### 节拍彩色圆形提示（新）

- 编辑动作 →「呼吸与节拍节奏引导」→ 每个阶段中间新增了**颜色块**，点它可自定义该阶段颜色；
- 内置模板默认：吸气=绿、呼气=红、保持/停顿=黄；
- 训练时屏幕中央显示一个大圆，背景就是当前阶段颜色、文字白色，描述（如"呼气·向后踢出"）字号约为倒计时数字的两倍，跟着阶段自动切换。

### 左右两侧分步（新）

编辑动作时勾选「左右两侧分步」，适合弹力带后踢腿这类单侧动作：

1. 一组内**先做左侧**目标次数；
2. 左侧完成 → 自动休息 **20 秒**，利用这段时间换到右侧；
3. 右侧完成 → 本组才结束 → 自动组间休息 → 下一组；
4. 历史记录里左右次数分开显示（左 X 次 / 右 X 次）。

> 旧的动作若"记录类型=左右侧型"也会自动按分步流程处理。

### 训练提醒

两个入口：

- 首页快捷区「训练提醒」（在训练历史之前，点它直接定位到提醒设置）；
- 底部导航「我的」→「数据与备份」→「训练提醒」。

用法：

1. 选类型（每天固定 / 单次 / 每小时）、填时间和内容；
2. 点「保存设置」把当前填写保存为默认值，下次打开自动带入；
3. 点「添加提醒」把它加入提醒列表；
4. 建议点「开启系统通知」并允许，这样后台也能收到。

三种类型：
- **每天固定时间**：如每天 `07:00` 提醒"起床啦，练套拉伸！"；
- **单次提醒**：指定某天某时，只响一次；
- **每小时提醒**：设起止时间如 `09:00`-`17:00`，期间每个整点响一次，适合"站起来活动"。

**到点提醒方式**：屏幕**弹窗** + **连续响铃**（最多约 11 秒，点"知道了"可停止）+ 语音播报 + 系统通知。列表里可开关、试响、删除。时间判断有 ±2 分钟容错，回到 App 时也会补检查，减少漏提醒。

> App 开着或退到后台时提醒最可靠；浏览器支持 `Notification Triggers` 时（部分安卓 Chrome），完全关闭也能按预约时间提醒。这是浏览器机制限制，不是故障。

### 一键复制并跳转 DeepSeek

位置：「我的」→「数据与备份」→「复制数据并跳转 DeepSeek」。复制动作库、课程和最近 5 条训练记录后调起系统分享面板，选 DeepSeek 即把数据带进输入框；不支持时回退网页版。不再打开 Google Play 商店页。

### 纯视频跟练

编辑动作勾选「纯视频跟练」后其他参数变灰失效，上传视频或填链接并保存；训练时视频放大播放，播完自动进入下一项。该模式暂不统计组数/次数/重量。

### 下拉刷新

任意页面顶部下拉只刷新当前页，不跳首页；当前菜单会被记住。弹窗内上下滑动是正常滚动，不触发刷新。

### 缓存清理

入口：首页快捷区「缓存清理」，或「我的」→「数据与备份」→「缓存清理（分级清理）」。区分**有用缓存**（当前版本离线页面）与**无用缓存**（旧版本残留），勾选后确认清理。训练数据和视频不在清理范围内。

## 数据与备份

- 动作、课程、训练记录和本地视频都存在 IndexedDB，不会自动上传。
- 请定期用「导出完整备份（JSON）」保存数据；JSON 备份会跳过大体积视频文件。
- 删除已上传视频：动作页 → 编辑该动作 → 教学视频栏点「移除视频」→ **保存动作**，视频文件才会真正删除并释放空间。
- 清理 Chrome 网站数据、卸载浏览器、更换手机都会导致本地记录丢失，请务必备份。
