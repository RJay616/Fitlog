# FitLog v1.2（Android PWA · 普通运动训练版）

FitLog 是个人运动训练记录与指导工具：动作库、训练课程、训练执行、历史趋势、数据备份全部保存在手机浏览器本地，不需要服务器。

> 本版本以 `index-1.html / styles-1.css / app-1.js / sw-1.js` 这套 FitLog 普通运动文件为基准修改，不是太极/气功版本。

## 升级方法

1. 用修改后的文件覆盖 GitHub Pages 仓库里的同名文件并提交。
2. 等待 Pages 发布完成后，手机下拉刷新一次或重新打开网页。
3. 如果已安装到桌面的 PWA 仍显示旧界面，删除桌面图标后重新安装即可。训练数据存在 IndexedDB，不会因重装 PWA 而丢失。

## 功能说明

### 下拉刷新

在任意页面顶部下拉，只刷新当前页面的数据，不会跳回首页；当前所在菜单会被记住。

### 组间休息与倒计时

- 进入休息时播放一次提示音；
- 剩余 3、2、1 秒各响一次短音；
- 休息结束播放三连提示音并自动进入下一组或下一个动作。

### 纯视频跟练

1. 在「动作」页添加或编辑动作；
2. 勾选「纯视频跟练」，下方组数、次数、重量、休息、节拍等参数会变灰失效；
3. 上传本地视频或填写视频链接并保存；
4. 把该动作加入课程并开始训练，视频会放大播放，播完自动进入下一项。

> 按你的要求，纯视频模式暂时不统计组数、次数和重量，后续需要时再开放参数统计。

### 缓存清理

两个入口：

- 首页快捷入口里的「缓存清理」；
- 底部导航「我的」→「数据与备份」→「缓存清理（分级清理）」。

分类：

- **有用缓存**：当前版本离线页面缓存，清理后联网打开会自动重建；
- **无用缓存**：旧版本残留缓存，可安全清理。

训练数据、动作视频和实际记录**不在**缓存清理范围内，请放心使用。

### 语音自检

在「我的」→「数据与备份」→「语音与提示音自检」：

- 测试滴滴音：检查提示音；
- 测试语音计数：检查系统中文语音。

如果语音断续，建议在手机「系统 → 文字转语音输出」中选择中文离线语音包，并关闭浏览器省电限制。

### 一键复制给 DeepSeek

在「我的」→「数据与备份」点击「复制数据并跳转 DeepSeek」，会把动作库、课程编排和最近 5 条训练记录整理成中文提示词复制到剪贴板，并自动打开 DeepSeek，直接粘贴即可。

## 数据与备份

- 动作、课程、训练记录和本地视频都存在 IndexedDB，不会自动上传。
- 请定期使用「导出完整备份（JSON）」保存数据；JSON 备份会跳过大体积视频文件。
- 清理 Chrome 网站数据、卸载浏览器、更换手机都会导致本地记录丢失，请务必备份。
