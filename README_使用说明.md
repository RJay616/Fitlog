# FitLog v1.4（Android PWA · 普通运动训练版）

FitLog 是个人运动训练记录与指导工具：动作库、训练课程、训练执行、历史趋势、数据备份全部保存在手机浏览器本地，不需要服务器。

> 本版本以 FitLog 普通运动版为基准（`index-1.html / styles-1.css / app-1.js / sw-1.js`），不是太极/气功版本。

## 功能说明

### 训练提醒（新）

位置：「我的」→「数据与备份」→「训练提醒」。

**首次使用**：先点「开启系统通知」并允许，否则通知无法弹到手机通知栏。

三种提醒类型：

- **每天固定时间**：如每天早上 `07:00` 提醒"起床啦，练套拉伸！"，每天自动触发一次；
- **单次提醒**：指定某一天的某个时间，只提醒一次；
- **每小时提醒**：设置起止时间（如 `09:00` - `17:00`），期间每个整点提醒一次，适合"站起来活动一下"。

添加后可在列表里开关（勾选框）、点「试响」测试声音、或删除。提醒触发时会响提示音 + 语音播报 + 系统通知，点通知可回到 App。

> 提醒可靠性说明：网页 PWA 的定时能力受浏览器限制。**App 开着或退到后台时提醒最可靠**；若浏览器支持 `Notification Triggers`（部分安卓 Chrome 支持），App 完全关闭也能按预约时间提醒；不支持时需要保持 App 在后台运行。这是浏览器机制限制，不是 App 故障。

### 一键复制并跳转 DeepSeek

位置：「我的」→「数据与备份」→「复制数据并跳转 DeepSeek」。

1. 先把动作库、课程编排和最近 5 条训练记录整理成中文提示词复制到剪贴板；
2. 调起**系统分享面板**，在面板里选择 DeepSeek，数据会直接带进输入框；
3. 若取消分享或浏览器不支持系统分享，则回退打开网页版 `chat.deepseek.com`，手动粘贴即可。

> 不再打开 Google Play 商店页，国内网络可正常使用。

### 节拍报数

- 有节拍的动作（如深蹲、俯卧撑）：**每个动作开始前先报"第 N 个"**，随后每秒滴一声掌握节奏，不再播报"吸气下蹲、呼气站起"等描述；
- 无节拍的动作（如平板支撑、臀桥）：每秒滴一声并累计秒数，直接跟着节奏做即可；
- 组间休息：进入响一次、最后 3 秒各响一次、结束响三连音。

### 语音音色设置

位置：「我的」→「数据与备份」→「语音音色设置」。

- **播报模式**：完整播报 / 仅报数 / 仅滴滴提示音；
- **语音音色**：默认「自动优选男声」；若手机系统没有可用中文声音，下拉会显示"系统暂无可用声音"——这是浏览器语音通道取不到系统 TTS 的限制，可在手机系统「文字转语音」里安装讯飞等中文引擎后再看，或改用「仅滴滴提示音」模式；
- **音调 / 语速**：默认音调 `0.9`、语速 `1.0`，可按需调整并试听。

### 下拉刷新

在任意页面顶部下拉，只刷新当前页面的数据，不会跳回首页；当前所在菜单会被记住。**在弹窗内部上下滑动是正常滚动，不会触发刷新。**

### 纯视频跟练

1. 在「动作」页添加或编辑动作；
2. 勾选「纯视频跟练」，下方组数、次数、重量、休息、节拍等参数会变灰失效；
3. 上传本地视频或填写视频链接并保存；
4. 把该动作加入课程并开始训练，视频会放大播放，播完自动进入下一项。

> 纯视频模式暂时不统计组数、次数和重量，后续需要时再开放参数统计。

### 缓存清理

两个入口：

- 首页快捷入口里的「缓存清理」；
- 底部导航「我的」→「数据与备份」→「缓存清理（分级清理）」。

分类：

- **有用缓存**：当前版本离线页面缓存，清理后联网打开会自动重建；
- **无用缓存**：旧版本残留缓存，可安全清理。

训练数据、动作视频和实际记录**不在**缓存清理范围内，请放心使用。

## 数据与备份

- 动作、课程、训练记录和本地视频都存在 IndexedDB，不会自动上传。
- 请定期使用「导出完整备份（JSON）」保存数据；JSON 备份会跳过大体积视频文件。
- 若想删除已上传的视频：动作页 → 编辑该动作 → 教学视频栏点「移除视频」→ **保存动作**，视频文件才会真正删除并释放空间。
- 清理 Chrome 网站数据、卸载浏览器、更换手机都会导致本地记录丢失，请务必备份。
